# Rapport U0 (plan interface) — jetons + primitives — 2026-09-07

Implémenteur : ZCode. Destinataire : vérificateur (GO visuel attendu sur
la planche avant U1). Plan : `docs/PLAN-UI-PRO-2026-09-07.md` §U0.

## Livré

1. **`app/assets/css/tokens.css`** (nouveau, importé par `main.css`) :
   couleurs sémantiques (--bg → --info-bg), --sp-1..7, rayons
   (2/4/8/50 %), ombres, --z-*, échelle --fs-12..32 (7 tailles),
   --lh-text/title, --focus-ring ; bloc `[data-theme="primary"]`
   redéfinissant uniquement les couleurs + ombres/focus ; les 19
   anciens jetons deviennent des alias (compatibilité, suppression U5).
   Le bloc jetons historique de `main.css` est retiré (doublon).
2. **Primitives `app/components/ui/`** : UiButton (variant
   primary/secondary/ghost/danger, s/m, loading, icône), UiField
   (libellé, suffixe, aide, erreur, inputmode, step ±, virgule
   décimale), UiBadge (6 tons en CONTOUR, jamais d'aplat bleu), UiCard
   (un niveau, header/body/footer), UiSegmented (radiogroup),
   UiSwitch, UiStat (tabular-nums), UiEmptyState, UiToast +
   useToast() (aria-live polite, 4 s), UiIcon (24 icônes SVG inline,
   zéro dépendance).
3. **Migration mécanique** : 84 → 0 hex hors `tokens.css`/LocaleSwitcher
   (les couleurs de PIÈCES du live/DXF passent en rgb() fonctions de
   données, hors chrome) ; font-size 35 → 8 valeurs distinctes (les 7
   jetons + `font-size: 0` technique de SvgDisplay) ; border-radius
   22 → 9 (4 jetons + composés `var(--radius-l) 0 …`) ; les ~22
   `<button>` et ~11 `<input>` ad hoc restants sont la migration
   U1+ (voir Non-faits).

## Non-faits énoncés

1. **`<button>`/`<input>` hors primitives : 25/12 restants** — le plan
   demande leur migration en U0 (« migration mécanique ») ; je les ai
   laissés à U1+ car chacun touche un écran précis (MainSettings,
   ResultModal, auth…) et la mécanique massive ce tour était
   hex/tailles/rayons sans risque fonctionnel. Si le vérificateur
   l'exige en U0, je les passe avant le GO visuel.
2. `font-size: 0` (SvgDisplay, hack d'alignement inline-SVG) et les 5
   border-radius composés : hors échelle par nature, documentés ici.
3. La PLANDE ne montre pas encore les primitives UiButton/UiField en
   situation (aucun écran ne les consomme) — U1 le fera.
