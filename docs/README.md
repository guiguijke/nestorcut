# Documentation NestorCut

Ce dossier ne garde que ce dont le code, la loi ou un contributeur externe
a besoin :

- [`dwg-license.md`](dwg-license.md) : licence et périmètre de l'import DWG
  (GNU LibreDWG, processus séparé).
- [`encryption-premium.spec.md`](encryption-premium.spec.md) : coffre
  zero-knowledge (fichier-clé), référence crypto et cycle de vie.

Ailleurs dans le dépôt :

- `AGENTS.md` : architecture, règles et pièges techniques pour les agents.
- `CHANGELOG.md` : journal des versions.

Plans, décisions, spécifications produit et audits sont tenus en privé par
le propriétaire ; les commentaires du code qui citent `specs/…` ou `docs/…`
renvoient à ces notes.
